## ✨ Key Improvements Made

1. **Apple-style Glassmorphism UI:** Integrated translucent frosted glass cards (`backdrop-blur-xl`) with crisp light borders and drop shadows.
2. **Dynamic Background Motion:** Custom Framer Motion floating bubble animation running continuously across the background grid.
3. **Enhanced Typography:** Glowing text gradient effects on key headlines to grab instant visual attention.
4. **Uncongested Academic Tabs:** Converted dense text blocks into clean, interactive tab selectors for Pre-Primary, Primary, Middle School, and Daycare stages.
5. **Interactive Bento Grid:** Redesigned STREAM education, skill-based learning, and campus features into visual cards with hover depth.
6. **Responsive & Accessible:** 100% mobile-friendly layout optimized for fast loading and smooth scroll transitions.
